<h3>Описание</h2>
<p>
Основная цель CXBOX — ускорить разработку типовых корпоративных приложений на основе Spring Boot. Фиксированный
контракт с пользовательским интерфейсом <a href="https://github.com/CX-Box/cxbox-ui" target="_blank">Cxbox-UI</a> позволяет бэкенд-разработчику создавать
типовые интерфейсы, описывая только JSON-метафайлы. В комплект входит полный набор типовых UI-компонентов корпоративного уровня —
виджеты, поля, макеты (views), навигация (screens).
</p>
</div>

</li>
</ul>
