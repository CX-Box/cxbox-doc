# Кнопки навигации браузера { #browser-navigation-buttons }

Стандартные кнопки навигации браузера (**Назад**, **Вперёд**, **Обновить**) **поддерживаются приложением не полностью**.

При их использовании браузер может восстановить кешированное состояние страницы, не соответствующее фактическому состоянию приложения. Это может привести к **неожиданному поведению**, в том числе:

* Потере несохранённых изменений
* Отображению устаревших данных
* Несогласованному состоянию интерфейса после перехода или перезагрузки

Поэтому **не следует полагаться на стандартные кнопки браузера** для навигации или обновления страницы в приложении.

---
Рекомендации

* Всегда явно сохраняйте изменения с помощью элементов управления приложения, прежде чем уйти со страницы.
* Используйте элементы навигации приложения вместо кнопок браузера.
