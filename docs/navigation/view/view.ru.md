## Представление (View) { #view }

**`View`** — основной строительный блок пользовательского интерфейса, из которого формируются экраны системы. Каждый экран создаётся на основе одного или нескольких View, внутри которых размещаются различные виджеты.

View определяет:

*   Структуру и компоновку содержимого экрана.
*   Порядок отображения виджетов.
*   Ширину каждого виджета (с помощью адаптивной сетки).
 

### Адаптивная сетка { #adaptive-grid }

Для размещения виджетов система использует адаптивную сетку из 24 колонок. Это позволяет гибко управлять их расположением и адаптивностью интерфейса.

| Значение | Поведение |
| :--- | :--- |
| **24** | Виджет занимает всю ширину страницы. *(По умолчанию)* |
| **12** | Виджет занимает половину ширины страницы (12/24 = 50%). |

> **Примечание:** некоторые специальные виджеты (например, `AdditionalList`) могут игнорировать стандартные правила ширины и вести себя иначе.

Если суммарная ширина двух идущих подряд виджетов в сетке составляет 24 или меньше, они располагаются на одной строке: первый слева, второй справа. Если суммарная ширина превышает 24, следующие виджеты автоматически переносятся на новую строку.

### Порядок отображения виджетов (`position`) { #widget-display-order-position }

Виджеты внутри View отображаются в порядке возрастания параметра `position`.

> **Рекомендация:**
> Используйте шаг 10 (например, `10`, `20`, `30`), чтобы в будущем можно было легко вставить новый виджет между существующими (например, на позицию `15`), не меняя остальные значения.

 
### Пример конфигурации View { #example-view-configuration }

| Параметр | Пример значения           | Описание |
| :--- |:--------------------------| :--- |
| **`id`** | `myexampleid`             | Уникальный идентификатор View в системе. |
| **`title`** | `My Title`                | Заголовок View, отображаемый пользователю (зависит от уровня вкладки). |
| **`template`** | `DashboardView`           | Шаблон View. `DashboardView` — стандартный (vanilla) шаблон. |
| **`url`** | `myexample357listexample` | Уникальный URL View. |
| **`rolesAllowed`** | `["CXBOX_USER"]`          | Список ролей, которым разрешён доступ к этому View. |
 
### Как добавить? { #how-to-add }
??? Example "Пример"
    Чтобы создать новый View, нужно:

    1.  Задать уникальный `id`
    2.  Указать `title`.
    3.  Определить список разрешённых `roles`.
    4.  `template`= `DashboardView`
    5.  Добавить URL для view.
    6.  Добавить виджеты, указав для каждого:
          *   Параметр `position` (управляет порядком отображения).
          *   Параметр `gridWidth` (управляет шириной в 24-колоночной сетке).
